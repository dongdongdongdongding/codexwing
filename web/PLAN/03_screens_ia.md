# 신웹 기획 — 03. 화면설계서 (와이어프레임·상태·인터랙션)

> 레이아웃: 좌측 고정 네비 + 상단 상태바 + 메인. 데스크톱 고밀도 / 모바일은 픽 우선 단일컬럼.
> 와이어는 구조용(ASCII). 실제 디자인 토큰은 [04_design_system.md](04_design_system.md).

┌ 요약 카드 ─────────────────────────────────────────────────────────────────┐

## 상태 매트릭스 (모든 화면 공통)
| 상태 | 표현 |
|---|---|
| 로딩 | 스켈레톤(레이아웃 유지, 깜빡임 없음) |
| 빈 | "오늘 픽 없음 — 스캔 안 돎/조건 미통과" + 다음 액션 |
| 지연 | 신선도 칩 노랑 ⚠ + 툴팁(최신일·원인) |
| 오류(외부API) | 폴백값 + "라이브 불가, 종가/캐시 표시" 배너 |
| 미성숙/낙관 | 배지·회색·경고문 |

## 반응형
- 데스크톱(운영자): 좌네비 + 멀티컬럼 고밀도, 상세 드로어 우측.
- 모바일(뷰어): 하단탭(개요/픽/성과), 픽 카드 세로 스택, 상세 풀스크린.
