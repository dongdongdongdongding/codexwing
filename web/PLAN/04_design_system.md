# 신웹 기획 — 04. 디자인 시스템 (서비스 최적화 · 템플릿 금지)

> 철학: **"정직한 퀀트 터미널"**. 제네릭 admin/대시보드 템플릿·클로드 기본 룩 금지.
> 페르소나(운영자+소수 신뢰뷰어)에 맞춘 **고밀도·고신뢰·고속** 시각 언어. 기획([02](02_functional_spec.md))·화면([03](03_screens_ia.md)) 반영.

---

## 1. 디자인 원칙 (5)
1. **신뢰가 미학이다** — 숫자의 정확/정직이 첫째. 알파·신선도·검증배지가 1급 시민. 장식 < 정보.
2. **밀도 있는 고요함** — 정보는 많되 시끄럽지 않게. 위계(크기·색·여백)로 정리. 차트정크 0.
3. **금융 정밀** — 등폭 숫자(tabular-nums), 정렬된 표, 천단위/부호/색 일관. 한 픽셀도 어긋나지 않게.
4. **즉답 인터랙션** — hover/click 즉시 반응(<100ms 체감), 낙관적 UI, 스켈레톤. 페이지 점프 없음.
5. **고유 정체성** — 우리 색/타이포/카드 형태로 "이 서비스"임을 각인. 부트스트랩/MUI 기본 룩 회피.

---

## 2. 브랜드 / 톤
- 이름(가칭): **SWING** — 마크 ◆(다이아). "찾아낸 진짜 엣지"의 은유.
- 톤: 차분한 전문가. 과장된 "🚀수익" 금지 — 절제된 자신감 + 정직한 경고.
- 다크 우선(트레이딩 장시간 응시). 라이트는 후순위.

## 3. 색 (다크 기준)
| 역할 | 값 | 용도 |
|---|---|---|
| bg | `#0B0E14` | 배경 |
| surface | `#141A24` | 패널/카드 |
| surface-2 | `#1B2330` | hover/중첩 |
| line | `#243044` | 구분선 |
| text | `#E6EDF3` | 본문 |
| text-mut | `#8B98A9` | 보조 |
| **up(상승/이익)** | `#26A269` | 양수 (한국장=빨강아님, 초록상승 통일) |
| **down(하락/손실)** | `#E0526A` | 음수 |
| **accent(브랜드)** | `#4C8DFF` | 강조·링크·B레인 |
| warn(낙관/지연) | `#E3B341` | 경고배지 |
| lane-swing | `#26A269` · lane-intraday `#4C8DFF` · lane-B `#A371F7` | 레인 식별색 |

> 색은 **의미 고정**: 초록=상승/이익/통과, 빨강=하락/손실, 노랑=주의/지연/낙관, 보라=B시장중립. 절대 장식용으로 안 씀.

## 4. 타이포그래피
- UI: Pretendard(한글) / Inter(라틴) — 깔끔·중립.
- **숫자: 등폭** (`font-variant-numeric: tabular-nums`) — 표·가격 정렬 필수.
- 스케일: 12(보조)·13(본문)·15(픽종목)·18(섹션)·24(지표) / 굵기 400·600·700.

## 5. 레이아웃·밀도
- 8pt 그리드. 카드 radius 10, 패널 radius 12. 테이블 행높이 40(데스크톱)·48(터치).
- 좌네비 폭 200, 상단바 56. 최대폭 1280(메인), 표는 풀폭 허용.
- 여백은 "조밀하지만 숨 쉬게" — 핵심픽은 크게, 근거는 접힘.

## 6. 핵심 컴포넌트 (고유 패턴)
- **픽 카드/행**: [순위배지][종목명 큰글씨 + 코드 작게 + ↗][실시간가 등폭][등락 색][확률 미니바][레인색 좌측바][정직배지]. 행 클릭=드로어.
- **정직 배지**: 알약형. 🟢SWING/🔵INTRADAY/🟣B · ⏳보유미완료 · ⚠낙관치 · 🔬shadow · 🕒지연. 색=의미고정.
- **신선도 칩**(상단바): `일봉6/26✅ 분봉6/26✅ 수급6/15⚠`. 지연시 노랑+툴팁.
- **알파/절대 토글**: 성과 화면 1급 컨트롤. 기본 알파.
- **미니차트**: lightweight-charts(분/일봉) — 격자 최소, 진입/목표선만.
- **확률 미니바**: 점수 시각화(꽉찬 막대 X, 얇은 인디케이터).
- **상태**: 스켈레톤(레이아웃 보존), 빈상태(다음액션 제시), 폴백배너.

## 7. 데이터 시각화 규칙
- 등락/손익은 색+부호+값 3중. 천단위 콤마. % 소수1~2.
- 에쿼티=단색 라인(영역 그라데 약하게), 0선 표시, 미성숙 구간 점선/회색.
- 차트정크 금지: 불필요 격자/범례/3D/그림자 X.

## 8. 모션
- 150ms ease 전환. 드로어 슬라이드, 값 변경시 색 플래시(0.4s). 과한 애니 금지.
- 실시간 시세 갱신=숫자 색 깜빡(상승초록/하락빨강) 후 복귀.

## 9. 접근성·반응형
- 명도 대비 AA(텍스트 4.5:1). 색맹 대비: 부호/배지 텍스트 병행(색만 의존 X).
- 모바일(뷰어): 하단탭, 픽 카드 세로, 상세 풀스크린, 운영탭 숨김.

## 10. 기술 매핑 (React)
- 컴포넌트: 디자인토큰 CSS변수 + 헤드리스(추후 결정) — **MUI/AntD 기본테마 그대로 쓰지 않음**(룩 고유화).
- 차트: lightweight-charts. 표: 가상스크롤(대량 픽). 상태: 폴링 훅(시세15s/픽5m).
- 토큰은 `web/frontend/src/theme.ts` 단일 진실원 → 위 색/타이포/스페이싱.
