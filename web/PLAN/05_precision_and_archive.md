## 1. ③ 정밀분석 (Precision Deep-Dive) — 로직 재설계

### 1.1 현재 문제 (왜 재설계)
- `QuantStrategy` + **yfinance** 의존 → KR 종목 부정확·느림·실시간 불일치.
- 제네릭 지표(이동평균/RSI) 위주 → **우리 데이터레이크·모델·근거를 안 씀.** 차별점 없음.

### 1.2 새 로직 — "우리 데이터로 한 종목을 끝까지 본다" (정직 종합)
입력: 아무 티커(코드). 우리 자산만 사용(yfinance 폐기):
| 블록 | 소스 | 출력 |
|---|---|---|
| **A. 모델 판정** | model_lane_scan(A 4레인)·b_engine(B) | 이 종목이 오늘 어느 레인에 픽됐나/점수·확률. 안 됐으면 "미픽 + 사유". |
| **B. 가격/차트** | px_long 일봉 + intraday 분봉 | 일봉·분봉 차트, 위치(20일고저·VWAP), 변동성(ATR), 추세. |
| **C. 수급** | flow.parquet | 외국인/기관/개인 순매수 5/20일(정규화 bps), 매수전환 여부. |
| **D. 펀더/이벤트** | dart_events·pead_surprise·fund | 최근 공시, 실적 서프라이즈(드리프트), 밸류. |
| **E. 레짐 맥락** | regime_classifier·market_data | 시장 레짐 + 이 종목의 레짐 적합도. |
| **F. 뉴스/비전** | news + vision_analysis(Gemini) | 뉴스 요약 + (선택)차트 이미지 패턴 코멘트. |
| **G. 종합 판정(LLM)** | market_intelligence(Gemini) | 위 A~F를 받아 **정직한 한 문단 판정**(강점/리스크/현 시점 매수타당성). 근거 인용. |

### 1.3 정직 원칙 (정밀분석)
- **점수 합성 금지의 투명성**: 각 블록 raw 수치 노출 + 종합은 "의견"으로 라벨(과신 X).
- 모델 미픽이면 솔직히 "모델은 안 골랐음" 표시(웹이 임의 추천 X).
- 데이터 신선도/결측 표시(예: 수급 6/15 지연).
- 백테스트/확률은 출처·표본·낙관여부 명시.

### 1.4 화면
```
[종목 코드 입력 ____]  [▶ 정밀분석]
┌ 헤더: 삼성전기(009150) 1,996,000 ▲0.3% │ 레짐:상승 │ 신선도칩 ─────────────┐
├ A 모델판정: 🟢코스피스윙 픽 p72% (오늘) · 🟣B 미픽 ───────────────────────┤
├ B 차트: [일봉][분봉] 위치 20일고가-3% VWAP+1% ATR 2.1% ──────────────────┤
├ C 수급: 외인5d +12bps▲ 기관 +3bps │ D 이벤트: 공시 없음·실적 N/A ──────────┤
├ E 레짐적합 / F 뉴스2건·차트패턴 코멘트 ───────────────────────────────────┤
├ G 종합(Gemini, 의견): "상승레짐+외인유입으로 단기 우위, 단 반도체 베타 리스크…" │
└ 매매 참고: (모델 픽일 때만) 진입/목표/보유 · ⚠근거는 정보, 투자권유 아님 ──────┘
```
### 1.5 API
`GET /api/analyze/{ticker}` → 위 A~G 블록 JSON. 무거운 블록(F vision/G LLM)은 지연로드/캐시.

## 2. ④ 성과 → 스캔 아카이브 (Scan Archive) 하위뷰

### 2.1 정의 (성과 집계와 다름)
- 성과 = **집계**(승률/알파/에쿼티). 아카이브 = **원장/이력**: 과거 모든 스캔의 픽 + 실현결과를 **행 단위로 열람·검색**. 감사추적 + 학습데이터.

### 2.2 소스
- Supabase `market_scan_results`·`scan_deep_reports`·`scan_universe_snapshots`
- 폴백/누적: `runtime_state/reports/archive/scan_archive_learning_dataset_all.csv` (이미 일일 export, 99MB), `ui/archive_data.py`(load_cached_market_scan_archive_rows)

### 2.3 기능
- 필터: 날짜범위·시장·레인·run_id·티커·결과(승/패/미해결).
- 행: 스캔일·run_id·종목명(코드)·레인·진입·확률·**실현수익·알파·결과배지**.
- 드릴: 행→그날 스캔 전체/그 픽의 top_deep_report.
- 내보내기: CSV(학습데이터셋과 동일 스키마).

### 2.4 화면
```

┌일자────┬run_id──────┬종목명(코드)──┬레인──┬진입──┬p%┬실현─┬알파─┬결과┐
│6/24    │SWING-…KOSPI│아이티센(124..)│스윙 │24800│65│-13%│-6% │📉패│
│6/26    │INTRA-…KOSDQ│뉴파워(144960)│장중 │ 6750│71│+4.7│+4.7│📈승│
└────────┴────────────┴──────────────┴─────┴─────┴──┴────┴────┴────┘
요약: 기간 N건 · 승률 X% · 알파 Y% (성과탭 집계와 연동)
```
### 2.5 API
`GET /api/archive?from&to&market&lane&ticker&result` (페이지네이션) · `GET /api/archive/export`
