## R2. Top 분석 = 픽 상세 드로어 흡수 + **내용 충실도**

## R3. 전역 언어 = **한국어 우선 + 어려운 용어 안내문구**
- 영어 약어/직역 금지. 사용자가 바로 인지할 한국어 라벨.
- 어려운 개념엔 **ⓘ 툴팁/안내문구 필수**. 표준 용어사전(전역 공유):
  | 용어 | 안내문구(툴팁) |
  |---|---|
  | 알파 | "시장(지수) 대비 초과수익. 시장이 빠져도 더 잘했는지" |
  | 시장중립 | "지수 등락과 무관한 순수 실력 부분(B엔진)" |
  | forward-shadow | "실거래 전, 실제 데이터로 성과를 관측·검증하는 단계" |
  | 수급 | "외국인·기관의 순매수 흐름(따라가면 유리한 경향)" |
  | 레짐 | "현재 시장 국면(상승/중립/하락)" |
  | VWAP | "거래량 가중 평균가 — 그날 평균 체결가 기준선" |
  | PEAD | "실적 발표 후 주가가 한동안 같은 방향으로 흐르는 현상" |
  | 보유 미완료 | "목표 보유기간(3~5일)이 아직 안 지나 평가 이른 픽" |
  | 낙관치 | "비용·슬리피지 미반영 추정 — 실제는 더 보수적" |
  | 확률(p) | "모델이 본 적중 가능성(과거 기준, 미래 보장 아님)" |
- 적용: 모든 지표 헤더·배지에 ⓘ. 처음 보는 화면엔 1줄 설명.

## R4. **백그라운드 스캔** (탭 이동/이탈해도 지속)
- 스캔 트리거 → 서버 비동기 작업(작업ID). 사용자가 탭 이동/페이지 닫아도 **서버에서 계속 실행**.
- 진행상태는 **어디서나** 조회: 상단바 진행칩(▓▓░ 67%) + ⑦운영 상세. 완료시 알림(토스트).
- API: `POST /api/ops/scan`→job_id, `GET /api/ops/scan/{job_id}` 폴링, 완료시 픽 자동 반영.
- 동시 스캔 1개 락(중복 방지). (기존 app.py `_run_model_lane_scan_job` 하트비트 패턴 + B서버 락 재사용.)

## R5. 픽 표시 = **티커명 + 코드 + 시장 배지** 동시
- 모든 픽 행/카드: **종목명** (크게) + **코드** (작게) + **[코스피]/[코스닥] 배지** + 레인배지(🟢스윙/🔵장중/🟣B).
- 배지로 시장 구분 충분(텍스트 컬럼 추가 불필요). 색맹 대비 텍스트 병기.
- 예: `삼성전기 (009150) [코스피] 🟢스윙`

## R6. 분봉/일봉 차트 = **토스급 탄탄함**
- 기준: 토스 차트처럼 **부드럽고·미니멀·견고·빠름·모바일터치 완벽**.
- 구현: lightweight-charts(TradingView) + 토스풍 토큰 — 얇은 라인, 부드러운 크로스헤어, 핀치/드래그 줌, 기간토글(1일/1주/1달/분봉/일봉), 진입·목표선 오버레이.
- 견고성: 로딩 스켈레톤, 결측/거래정지 처리, 빈상태, 분↔일 즉시토글, 리사이즈 안정.
- 위치: 픽 드로어 + 정밀분석③. 데이터: 일봉 px_long / 분봉 intraday 캐시(+장중 KIS 라이브).
