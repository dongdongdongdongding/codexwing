## 0. 이론 프레임 — 우리 결과들의 숨은 패턴

지금까지의 음성/양성 결과를 나란히 놓으면 축이 갈린다:

| 축 | 시도 | 결과 |
|---|---|---|
| **횡단면** (어느 종목?) | 가격패턴, 수급 피처, DART 피처, 섹터, 소형주 | **전부 음성** (플라시보 동일) |
| **시간축** (오늘 걸까 말까?) | 직교축(미국 오버나이트·환율·이벤트시계), idx_vol 가드, 기권(abstention) | **양성 흔적** (시장초과 CI>0, +2% CI>0) |
| **구조축** (계약·실행·합성) | 출구계약 교체, 시장중립화(B), dynamic exit | **양성** (CI>0 전환) |

이유는 시장구조로 설명된다. 한국 횡단면은 **세계에서 가장 경쟁이 심한 리테일+기관 혼합 시장**이고,
공개정보(가격·수급·공시)의 종목 간 상대 랭킹은 이미 가격에 있다. 반면 시간축(오늘 시장 전체의
베이스레이트)은 **아무도 재정거래로 소거할 수 없다** — 시장 전체를 공매도해 헤지하는 것은 개별 종목
알파를 소거하는 것보다 비싸고 제약이 많다(한국은 공매도 규제까지 겹침). 구조축(계약·사이징·합성)은
경쟁자가 없는 우리 내부의 비효율이다.

**EV 분해로 쓰면:**
```
pick_EV(t) = base_rate(시장, t) × skill(모델, 횡단면) × payoff(계약) − costs(실행)
```
- skill: 검증 완료, modest, 더 짤 수 없음 (3연속 음성)
- base_rate(t): 6월 붕괴의 정체. **예측 대상이지 상수가 아님** ← 시간축 연구
- payoff: 출구 연구로 첫 증명. 더 남음 ← 구조축
- costs: 진입 전술 ← 구조축
- 그리고 이 위에 **합성**(스트림 간 상관)이 포트폴리오 EV를 결정

## 1. 시장구조 관점의 신규 재료 (경제학자·실무자 사고)

**(a) 한국 시장의 레짐 척추 = 외국인×환율.** KOSPI의 한계가격결정자는 외국인이고 외국인 플로우는
환헤지 캐리 논리로 USD/KRW에 묶여 있다. 리스크오프 = 원화약세 + 외인매도의 이중고. 레짐 예측기의
코어는 지수 모멘텀(후행)이 아니라 **환율 변화율 + 외인 순매수 집계 + KOSPI200 선물 베이시스**(실시간
기관 심리)여야 한다. ← B1 설계 입력

**(b) 기계적(가격 무감각) 수급은 소거되지 않는 엣지 계열.** 상대가 "가격과 무관하게 반드시 거래해야
하는" 플로우는 구조적으로 살아남는다:
- **반대매매 캐스케이드**: 급락일 다음날 아침 신용융자 강제청산(시장가) → 고신용잔고 종목의 기계적
  아침 딥과 리바운드. 신용잔고 데이터 필요(KRX/KIS).
- **보호예수 해제**: IPO 락업 만료 = 캘린더에 공개된 공급 쇼크(DART/KIND 일정).
- **레버리지 ETF 리밸런스**: 큰 양봉일 종가에 KODEX/KOSDAQ150 레버리지가 기계적 매수 → 종가 모멘텀
  증폭과 익일 되돌림.
- **12월 대주주 양도세 회피 매도 → 1월 소형주 반등** (한국 고유 계절성, 문헌 다수).
- **동시만기일(네 마녀)·MSCI 리밸런스 종가 플로우.**
이것들은 "같은 라벨 위 피처 확장"이 아니라 **이벤트-시간 진입/회피 규칙**이라는 다른 신호군이다.
특히 회피측은 전례가 있다(수급 손실배제 가드 +31.9%p win-delta — 수급은 선별엔 무용, 회피엔 유효).

**(c) 테마 집중은 숨은 단일 베팅.** KOSDAQ 1~4월 성과의 일부는 테마 급등장 베타. top2 픽이 같은
테마면 분산이 아니라 한 베팅이다. theme_cache로 픽의 테마 중복을 측정·제한하는 것은 실무자급
리스크 컨트롤이고 6월형 손실의 완충이다.

**(d) 강제 top-2는 구조적 비최적.** 매일 2픽 강제는 "확신 없는 날에도 베팅"을 강제한다. 분봉
분류기 연구에서 기권(abstention)이 +2% CI>0였다. calibrated 확률 발행 + 확신 가중 커버리지(0~5픽)가
수동 매매 UX와도 정합(사용자는 확신도를 보고 사이징).

**(e) 연구방법 경고 (연구자).** 시간축 연구의 표본은 종목-일이 아니라 "월"이다 — 통계력이 약하다.
그래서 rule-first + 구조적 사전근거(위 (a),(b)) + 긴 역사(px_long 8년, 환율/지수 수십 년)가 필수이고,
ML은 마지막에만. 이것이 v1의 P1을 그대로 두되 설계 입력을 바꾸는 이유.

## 2. 재수립된 프로그램

### Phase A — 진단 (2~3일)
- **A1 (=v1 P0) 스트림 합성 감사**: forward 원장 전부 → 상관·중첩·합성 EV/MDD → 15% 산수.
- **A2 (신규) 스킬/베이스레이트 분해**: 6월 붕괴가 스킬 붕괴인가 베이스레이트 붕괴인가.
  같은날 유니버스 대조(픽 hit − 유니버스 hit)로 월별 스킬을 분리. **이 답이 Phase B의 설계를 결정**
  (베이스레이트 문제면 시장타이밍, 스킬 문제면 모델 리프레시 주기).

### Phase B — 시간축 (2~3주, 핵심)
- **B1 (=v1 P1 재설계) 베이스레이트 예측기**: rule-first 3상태. 입력 = USD/KRW 변화율, 미국 오버나이트
  (SOX/NASDAQ), 외인 순매수 집계, 선물 베이시스, breadth(상승종목비율·신고저), 변동성 구조.
  지수 모멘텀은 참고 피처로 강등. 8년 다중레짐 OOS + 셔플 플라시보 + LOMO + 기회비용 명시.
- **B2 (신규) 메타라벨링**: 1차 모델(현행 랭커)은 그대로, 2차 모델이 "이 픽이 이 맥락(레짐·테마·
  변동성)에서 성공할 확률"을 학습 → 사이징/기권 결정. 수급·이벤트가 횡단면에선 죽었지만
  **모델 신뢰도의 시계열 예측**에선 살아있을 수 있다(다른 축). calibrated 발행 + 강제 top-2 폐지 검토 포함.
  게이트: 동일 폴드, 맥락 셔플 플라시보, 커버리지-EV 곡선.

### Phase C — 구조축 (1~1.5주)
- **C1 (=v1 P2) 목표함수 정렬**: 라벨을 y3 터치확률 → 계약 실현 net수익으로.
- **C2 (=v1 P3) 진입 전술 + 오버나이트 분해**: 종가 vs 익일 시가/VWAP, 동시호가 비용 실측.

### Phase D — 기계적 수급 캘린더 (2주, Phase B와 병렬 가능)
- **D1 데이터 확보**: 신용잔고(KRX 정보데이터시스템/KIS), 보호예수 해제 일정(KIND), 만기/리밸런스 캘린더.
- **D2 회피측 우선 검증**: 고신용잔고 + 급락 다음날 회피, 락업 해제 주간 회피, 12월 소형주 회피 —
  기존 레인의 손실배제 가드로 (선별이 아니라 회피가 수급의 검증된 사용처).
- **D3 진입측은 그 다음**: 반대매매 리바운드, 1월 효과, 레버리지 ETF 되돌림 — 각각 독립 라벨로,
  현실 체결가 + 플라시보(무작위 날짜 대조) 필수.

### 상시 — 리스크 컨트롤
- **R1 테마 집중도**: 픽의 테마 중복 측정(theme_cache), 동일 테마 2픽 제한 규칙의 forward 효과 관측.
- exit shadow 누적(계약 결정 대기), touch5_dd10 표본 게이트, B forward-shadow 유지.

## 3. 순서

```
A1+A2 (진단 2~3일)
  ├─> B1 베이스레이트 예측기 ──> B2 메타라벨링 ──> C1 목표정렬 ──> C2 진입전술
  └─> D1 데이터 확보 ──> D2 회피측 ──> D3 진입측   (B와 병렬)
R1 테마 집중도: A 이후 상시
```

## 4. 하지 않을 것 / 게이트

- 하지 않음: 같은 라벨 위 횡단면 피처 확장, 가격패턴 재방문, 소형주, 눈대중.
- 모든 주장: 비용후 EV + 현실 체결가 + 플라시보 + 다중레짐 OOS + (집계피처면) 랜덤 플라시보.
- 시간축 주장: 월 단위 표본 한계 명시, rule-first, 기회비용(죽인 좋은 달) 보고.
- 판정 단위: 포트폴리오 EV+MDD (단일 레인 아님).

## 5. 최종 목표와의 연결

- **75% 승률**: 출구계약(검증됨) + C1 랭킹 정렬 + B2 기권(확신 없는 날 안 삼).
- **15% 수익**: A1 합성 산수 + B1 붕괴 월 회피 + D 신규 이벤트-시간 엣지 + C2 비용 회수.
- **8:2 안전**: B1 무거래/사이징 + R1 테마 분산 + D2 회피 가드 + 사이징(스톱 금지 확정).
