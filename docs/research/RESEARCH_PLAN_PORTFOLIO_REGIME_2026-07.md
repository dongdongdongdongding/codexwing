# 연구 계획: 시그널 사냥 종료 → 포트폴리오·레짐·목표정렬 (2026-07-03)

Author: Claude (제안) / 결정: 운영자. Status: 정렬 대기.

## 0. 왜 이 계획인가 — 증거가 가리키는 방향

지금까지의 연구가 확정한 것:

| 확정 사실 | 출처 |
|---|---|
| KR 가격패턴 엣지 없음 (분봉·일봉·소형주, 진입순간 ~50/50) | RESEARCH_LOG §1, B트랙 종결 |
| 수급·이벤트 피처 증분 없음 (플라시보 동일, 3연속 음성) | RESEARCH_LOG §5-A |
| 살아남은 것 = modest 횡단면 ML(B) + **계약/실행 개선**(출구 연구) | RESEARCH_LOG §2, §5-C |
| 최대 위협 = 레짐 균열 (2026-06 양시장 hit 52.8% 동반붕괴, idx_mom20은 20일 지연이라 못 잡음) | RESEARCH_LOG §5-B |
| 승률 75%는 출구계약으로 도달 가능. **15%는 단일 레인이 아니라 합성의 문제** | §5-C + 이 문서 |

결론: 같은 라벨에 피처를 더 붓는 연구는 기대값이 소진됐다. 남은 기대값은 **시그널 바깥의 4개 레이어**에 있다 — 합성(portfolio), 레짐(regime), 목표(objective), 실행(execution). 전부 기존 데이터·기존 원장으로 검증 가능하고, 새 외부 데이터가 필요 없다.

## P0. 스트림 합성 감사 — "15%가 산수로 되는가" (측정, ~1일)

**가설**: 시스템엔 이미 forward 원장이 있는 스트림이 6개+ 있다(swing ensemble, KOSPI intraday, KOSDAQ VWAP guard, B 시장중립, NASDAQ session, PEAD/firsttouch shadow). 상관이 낮다면 합성 포트폴리오가 단일 레인보다 훨씬 좋은 EV/MDD를 낸다. 아무도 이걸 측정한 적 없다.

**방법**: 모든 forward 원장 → 스트림별 일수익 시계열(통일 사이징) → 상관행렬·픽 중첩률·합성 EV/MDD 곡선 → **트레이드/일 × EV × 사이징으로 15% 연환산의 정직한 산수**.

**게이트**: forward 원장만 사용(인샘플 없음). 산출물: 합성 리포트 + "현 스트림 구성으로 도달 가능한 연수익 구간" 명시.
**킬 기준**: 없음(측정이므로). 단, n<30 스트림은 참고로만.

## P1. 레짐 상태 모델 → 레인 게이팅 (핵심, ~1주)

**가설**: 2026-06형 붕괴는 idx_mom20(후행)보다 빠른 신호 — 미국 오버나이트 연쇄, 환율 변화율, 지수 변동성 구조, 시장 폭(breadth: 상승종목비율·신고가-신저가) — 로 사전 감지 가능하다. 일봉 연구에서 직교축(미국 오버나이트·환율·이벤트시계)이 유일하게 시장초과 CI>0를 되살린 전례가 근거.

**방법**:
1. rule-first 3상태 분류기(RISK_ON/NEUTRAL/RISK_OFF) — 해석가능한 소수 지표. ML은 rule이 부족할 때만.
2. px_long 8년(2018-2026)으로 상태별 레인 조건부 EV 측정 — 인트라데이 패널은 1년뿐이므로 일봉 프록시(터치 라벨)로 장기 검증 + 최근 1년 실패널로 확인.
3. 적용: RISK_OFF → 인트라데이 레인 무거래/사이징 축소, B(시장중립)는 유지. 포트폴리오 레벨 판정.

**게이트**: 다중년 OOS, 레짐 라벨 셔플 플라시보, 월 단위 LOMO, **기회비용 명시**(게이트가 죽이는 좋은 달). 판정 지표 = 포트폴리오 EV+MDD, 단일 레인 아님.
**킬 기준**: 셔플 플라시보와 구별 불가하거나, 6월형 회피 이득 < 좋은 달 손실이면 폐기하고 사이징-온리로 후퇴.

## P2. 목표함수 정렬 — 터치 확률이 아니라 계약 실현수익을 학습 (~1주)

**가설**: 현행 모델은 y3(터치 확률)을 학습하지만 P&L은 계약(터치익절→5d)에서 나온다. "hit은 높은데 수익이 음"(2026-05 KOSDAQ)인 픽을 랭커가 구분 못 하는 이유. 라벨을 **계약 실현 net 수익**으로 바꾸면 랭킹이 돈에 정렬된다.

**방법**: 같은 패널·같은 폴드에서 라벨만 교체(exit_t5_h5/exit_t10_h5 시뮬 수익 — §5-C 기계 재사용). 회귀 or "net>cost" 분류 + EV 랭킹. BASE(y3) 대비 동일 폴드 대조.

**게이트**: 동일 폴드 페어 비교, 라벨 셔플 플라시보, 월별 바닥, 픽 중첩률 보고(무엇이 바뀌는지).
**킬 기준**: 페어 비교에서 EV 개선이 월별로 일관되지 않으면 폐기.

## P3. 진입 전술 + 오버나이트 분해 (~3-4일)

**가설**: (a) 레인 수익의 상당분이 오버나이트 갭일 수 있다 — 그러면 종가 진입은 이미 최적이고, 아니라면 익일 VWAP/시가 분할 진입이 슬리피지를 회수한다. (b) 진입 개선은 작지만 모든 트레이드에 곱해진다.

**방법**: 레인 픽의 3~5d 수익을 오버나이트/장중 성분으로 분해(분봉 캐시), 종가 vs 익일 시가/VWAP 진입 EV 차이 실측.

**게이트**: 현실 체결가(§3 체크리스트 1), 비용후. **킬 기준**: 차이 < 0.1%p/트레이드면 현행 유지.

## 순서와 논리

```
P0 (측정, 1일) ──> P1 (레짐, 핵심) ──> P2 (목표정렬) ──> P3 (진입)
                    └─ P0의 스트림별 조건부 성과가 P1의 게이팅 대상을 정의
```

- 하지 않을 것: 같은 라벨 위 피처 확장(3연속 음성), 가격패턴 재방문, 소형주.
- 병행 유지: exit shadow 자동 누적(계약 결정 대기), touch5_dd10 표본 게이트, B forward-shadow.
- 모든 단계: beads 이슈 + RESEARCH_LOG 기록 + git commit/push를 작업 단위마다.

## 최종 목표와의 연결

- **75% 승률**: P2(랭킹 정렬) + 출구계약(이미 검증) → 승률축 달성 경로.
- **15% 수익**: P0(합성 산수) + P1(붕괴 월 회피) + P3(트레이드당 EV 가산).
- **8:2 안전**: P1(레짐 무거래)이 '2'의 방어를 담당, 스톱 대신 사이징(§5-C 확정).
