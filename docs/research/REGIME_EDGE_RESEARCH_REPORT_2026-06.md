## 1. 연구 목표 & 규율

### 1.1 목표 (사용자 정의)
- 최종 목표: 매일 시장 측정 → 시그널 → 사용자 매매. 목표 정확도/수익률(75%/15%는 daily로 불가 판정, 현실적 엣지로 전환).
- 엣지의 작동 정의: **"후보 5개를 뽑으면 3-4개는 수익(60-80% 적중)"** — universe EV가 아니라 실제 추천 픽의 적중률, survivorship-free, 실행 현실 반영.
- 장세별(하락/보통/상승)로 **각각 살아남는 모델**을, **시장(KOSPI/KOSDAQ) 분리**해 탐색.

### 1.2 연구 규율 (스스로에게 먼저 적용한 과적합 방지 원칙)
1. **Survivorship-free**: 오늘 시총 상위 N 선택 금지(전향적 편향). 전 종목 또는 시점-유동성 기준. 저유동성 필터는 검증 후 단계.
2. **실행 현실성**: 신호가격이 아니라 **open[t+1] 진입**, 왕복비용 0.6% 차감.
3. **단일 에피소드 금지**: 풀링 통계가 한 국면(예: 2025-04 V바닥)에 지배되는 함정 → fold/월/연도로 분해해 **모든 기간 안정성** 요구.
4. **선택편향 제거**: 부분집합 탐색 후 반드시 **nested 검증**(앞 구간 선택 → 손대지 않은 뒤 구간 테스트).
5. **모델 다양화**: 단일 모델 금지 → LightGBM/XGBoost/CatBoost/ExtraTrees/Logistic 앙상블.
6. **눈대중 금지**: "고점/저점" 같은 1차원 직관 대신 forward-검증된 수치만.
7. **없는 엣지 만들지 않기**: forward 검증 안 되는 신호는 운영에 올리지 않음.

## 3. 방법론

- **레짐 분류:** 시장별 자기지수 20일 모멘텀 terciles. KOSPI=KS11, KOSDAQ=KQ11. DOWN(<-2) / NORMAL(-2~2) / UP(>2). 진입시점 known(no look-ahead).
- **타겟:** win5/10/20(방향, 비용후 양수), big5/10/20(빅무버 +7/10/15%), 시장초과(relout, exec−지수 forward), 연속상승(fwd_3up).
- **선별:** 시장×일자 횡단 랭크 후 일별 top-K(주로 5). 고확신 abstention(확률 절대상위)도 별도 검증.
- **모델:** 탐색=LightGBM(빠름), 최종검증=앙상블(LGBM+XGBoost+CatBoost+ExtraTrees+Logistic, 각 prob을 per-day 랭크 후 평균).
- **검증:** ① walk-forward(확장 fold), ② **nested**(앞 65% 선택→뒤 35% 테스트), ③ 연도별/월별 분해 안정성, ④ 픽 유동성(liqR=일중 유동성 백분위) 추적.
- **비용:** 왕복 0.6% 차감.

## 4. 하락장 엣지 (검증된 지배 엣지) — 상세

### 4.1 1차 발견 (396 유동종목, 2024-2026)
- 레시피: 앙상블 × **수급피처만**(가격은 노이즈만 더함, supply_only > ALL) × **상승장 제외** × **10일 보유** × top2-3.
- walk-forward 4 fold: top2/day **59-65%**, net +1.5~3.2%. 4기간 전부 양수.
- 엄격 정지 holdout: 52-55%(한 달 33% 변동) → 재학습 필요·월변동 존재.
- 코어 피처 중요도: **both_buy(외인·기관 동시매수) 압도 1위, frgn_streak(외인 연속매수) 2위.**
- 단일 lgbm 55% → **앙상블 63%** (모델 다양화가 노이즈 제거).

### 4.2 본 탐색 (전 종목 2,674, 시장분리, 장세분리 딥서치)

### 7.3 출구 타이밍 결론

4. **최저/최고 폭 큼(5일 -42~+45%)** = 개별픽 변동 큼 → **5종목 분산 필수**(엣지는 평균·승률에, 개별 손실은 못 막음).

## 11. 방법론 업그레이드 — Claude 피드백 구현 (2026-06-18~19)

### 11.1 5개 결함 구현 결과
| 결함 | 수정 | 결과 |
|---|---|---|
| 1. 횡단 z-score 랭크 | 종목 자기시계열 z(rolling252) + **calibrated probability**(isotonic) + p≥τ 절대임계 발행 | calibration 오차 0.025-0.032(통과). 사용자 목표("60%+ 닿는 후보만 발행, 아니면 0") 형태 달성 |
| 2. 종가 라벨 | **first-touch 삼중배리어**(+5%상단/−s%하단/5일, 일중 고저) | **가장 valid.** first-touch ≫ 종가 (NORMAL소 72% vs 종가 39%) — 종가가 익절거래를 묻었음 |
| 3. 중첩/검정력 | 비중첩(5일간격)+bootstrap CI+연도별 | **NORMAL 소형 72%가 최근2년뿐, 8년 47% 신기루임을 적발** |
