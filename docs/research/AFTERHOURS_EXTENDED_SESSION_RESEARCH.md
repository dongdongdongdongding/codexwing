# 정규장+애프터장(확장세션) intraday 연구 — 2026-06-26 시작

운영자 지시: 현재 intraday 모델은 정규장(09:00–15:30) 전용이라 애프터장/NXT(15:30–20:00) 움직임을
못 본다. **정규장+애프터장 통합** 데이터로 새 트랙을 시작한다. (현재 검증된 정규장 모델과 별도)

## 1. 데이터 토대 — 확보됨 (2026-06-26)

핵심 발견:
- KIS `daily_minute_bars(market_div="J")` = **15:30에서 잘림** (정규장 KRX만). input_hour를 18/20시로
  줘도 애프터장 0봉.
- **`market_div="UN"`(통합 KRX+NXT)** 또는 `"NX"`(NXT)로 호출하면 **08:00~19:59 전체 확장세션**이 나옴.
  - 삼성전자 2026-06-25 매핑: 프리장 08:00–09:00 + 정규장 381봉 + **애프터/NXT 260봉** = 고유 691봉.
- 즉 정규장+애프터장 1분봉 데이터가 **존재하며 수집 가능**.

수집기: `~/research_cache/build_intraday_ext.py` → `~/research_cache/intraday_ext/{code}.parquet`
(정규장 전용 `intraday/`와 **분리**, production 무관). `market_div="UN"`, 08:00–20:00 필터, 날짜 증분.

## 2. 가설

애프터장/NXT 가격 행동(15:30–20:00)이 정규장-only 모델이 놓치는 **익일 방향 정보**를 담는다:
- 장 마감 후 기관/뉴스 반응, 시간외 단일가 수급, NXT 연속/반전 패턴.
- 특히 정규장 종가 이후 애프터장에서 추가로 움직이는 종목 → 익일 갭/연속 가능성.

## 3. 방법 (과적합 규율 적용 — [[research_discipline_ev_not_eyeball]])

- **피처**: 정규장 피처(기존 ITF) + 애프터장 피처(afterhours_ret, afterhours_vol, aft_vwap_dist,
  close_to_aftclose, nxt_continuation, aft_volume_frac 등).
- **타깃**: 3일내 +5% 터치(현 intraday와 동일 비교) — 진입 후보: 정규장 종가 vs 애프터장 종가(20:00).
- **검증(필수)**: walk-forward OOS + 같은날 size-matched 대조 + forward 검증. naive CI 금지.
  애프터장 단독이 정규장 위에 **증분(increment)** 있는지 = 정규장-only 모델 대비 Δ로만 판정.
- **랜덤 플라시보**: 애프터장 집계 피처는 [[sector_no_increment_placebo]] 교훈대로 랜덤 대조 필수.

## 4. 리스크 (선제 기록)

- **NXT 신생(2025)** → 히스토리 짧음. 장기 walk-forward 표본 부족 가능.
- **애프터장 유동성 희박** → 많은 종목이 애프터장 거래 거의 없음. 고유동 상위부터(N=300) 시작.
- **과적합 위험 큼** → 피처 많고 표본 적음. 증분 없으면 폐기(정규장 모델이 이미 검증됨).
- 시간외 단일가(10분 체결)와 NXT 연속체결 혼재 → 봉 의미 해석 주의.
