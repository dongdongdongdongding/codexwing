# 사전등록: DEGRADE 5레인 부검 (2026-08-14)

> 질문은 "**왜 죽었는가**"다. 후보 원인 6종을 **결과를 보기 전에** 갈라놓고, 각 원인마다
> "무엇을 보면 구분되는가"를 수치로 고정한다. 부검 중 눈에 띄는 새 조건 셀은 결론에 반영하지
> 않는다(§낚시 방지). 판정은 이 문서의 기준으로만 내린다.
>
> 이 트랙이 실패하는 방식은 정해져 있다 — **"레짐 탓"이라고 편하게 결론 내고 사이징을 원복**하는
> 것이다(§40 PKG-B ① S1 시나리오: DEGRADE 원복 시 −12.3%/yr). 그래서 "레짐"에도 기각 조건을
> 먼저 박는다.

## 2. 판정자 먼저 심판한다 — C0 (게이트 산식 결함)

원인 6종에 들어가기 전, **판정을 만든 산식**을 먼저 검증한다. 이건 죽음의 원인이 아니라 판정의
원인이므로 따로 센다.

`multi_agent/tools/report_research_recursion_gate.py` 실측:
```
DEGRADE  ⟺  CI_hi < expect_ev*0.5   OR   mean <= 0
CI       =  iid 부트스트랩 400회, 픽 단위 재표집
```

- **C0-a 어느 팔이 발화했는가.** 5레인 전원 fwd EV < 0 → **전부 `mean <= 0` 팔**이다.
  즉 판정은 "기대에 못 미쳤다"가 아니라 "**부호가 음수다**"에서 나왔다.
  → **부검 질문을 "왜 5.65에 못 미쳤는가"가 아니라 "왜 음수인가"로 고정한다.**
  기대치 5.65 vs 0.65의 크기 차이는 현 판정과 무관하다(단 §4의 C4/C6 판정에는 결정적).
- **C0-b iid 부트스트랩 과신.** 중첩창·같은날 클러스터 픽에 iid 재표집은 §33이 스스로 자인한
  결함과 **같은 결함**이다. 측정: r = (iid CI 폭) / (날짜클러스터 블록 CI 폭).
  - **r ≥ 1.5 → 게이트 유의성 과장 확정.** 연구 판정과 분리해 게이트 산식 수리 티켓을 별도 제안
    (본 부검의 결론에 섞지 않는다).
  - r < 1.2 → 게이트 산식 무죄.
- **C0-c 비용 가정 비대칭.** B 계열만 cost=0.0. 근거는 "시장중립 α라 백테스트와 동일 기저".
  이 근거의 타당성은 C3에서 심판한다.

## 4. 판별 매트릭스 — "무엇을 보면 구분되는가" (수치 사전 확정)

### 공통 추정기 (한 번만 정의, 전 원인에 동일 적용)
- 단위 = 픽. 클러스터 = **신호일**. 부트스트랩 = **날짜클러스터 블록 부트스트랩**(연속 5영업일
  블록으로 날짜를 묶어 재표집), **2,000회, 95% CI**. iid CI도 병기(C0-b 측정용).
- `net` = 원장 필드 − cost (게이트와 동일: 0.30/0.30/0.00/0.00/0.25).
- **α_mn (시장중립)** = 픽 net − *같은날·같은계약* 시장(또는 적격풀) 수익.
- **α_sel (선별)** = 픽 net − *같은날* 동수 랜덤티커 평균(동일 적격풀: 유동성·시장 필터 일치),
  200회 반복 순열 p값 동반.
- 부호 일관성은 창이 6~8주뿐이라 **연도 대신 주(週) 단위**를 쓴다. **이 대체물로는 "생존"을
  주장할 수 없고 "기각"만 가능**함을 사전에 못박는다.

### C1 표본 미성숙
| 통계 | 정의 |
|---|---|
| S1a 미성숙률 u | 1 − n_scored/n_rows (실측: itd 0.21 / swing 0.24 / nas 0.25 / b 0.02) |
| S1b 정산속도-부호 결합 | mean(net \| 정산 ≤3d) − mean(net \| >3d) |
| S1c 검정력 | 블록 CI 폭 |

- **확정**: u ≥ 0.20 **AND** \|S1b\| ≥ 1.0pp **AND** 블록 CI가 0과 expect×0.5를 **모두** 포함
- **기각**: 블록 CI **상한 < 0** (음수가 확정적) → 미성숙으로 설명 불가
- **판정보류 자동 발화**: 블록 CI 폭 ≥ 2 × \|expect_ev\|
- 주의: itd·swing·nas 세 레인 모두 u가 사전 임계 이상 → **C1을 사전에 배제하지 않는다.**

### C2 레짐 전환
| 통계 | 정의 |
|---|---|
| S2a | α_mn 평균 + 블록 CI |
| S2b | α_mn > 0 인 주(週) 비율 |
| S2c | 총 손실 중 상위 3개 신호일이 차지하는 비중 |
| S2d | 백테스트를 forward 창의 레짐 구성(`mkt_state` 분포·`mkt_dd20` 분위)으로 재가중 → `expect_regime` |

- **확정**: α_mn 블록 CI **하한 > 0**(시장중립으로는 살아있음) **OR** (S2c ≥ 70% **AND** S2b ≥ 60%)
- **기각**: α_mn **상한 < 0** **AND** S2c < 40% (손실이 창 전체에 고르게 퍼짐 = 국면 사건이 아님)
- **파생 판정 → C4/C6로 이관**: `expect_regime` ≤ 0.5 × `expect_ev` 이면 **동결 기대치가
  레짐 무지**였다는 뜻 — 레인 사망이 아니라 **기준선이 틀린 것**이다(§5 등급 C).

### C3 집행 가정 붕괴
| 통계 | 정의 |
|---|---|
| S3a Δ_entry | 진입 = **익일 max(open, 트리거레벨)** 로 재산출한 EV − 원장 EV. 필드: swing `entry_open` / itd `entry_reference_price` / b `entry_close` / nas `entry` |
| S3b Δ_cost | 분봉 기반 실측 왕복비용(스프레드+슬리피지+세금) − 가정 비용(0.30/0.30/0/0/0.25) |
| S3c | 터치익절 체결 가정 — **재검증하지 않는다.** §40 PKG-B ③에서 이미 통과(EV 임팩트 −0.04pp). 각 레인 계약이 실제로 터치익절인지 **확인만** 한다 |

- **확정**: (\|Δ_entry\| + \|Δ_cost\|) ≥ 1.0pp **AND** 그것이 부족분 (0 − fwd_EV) 의 **≥ 30%** 설명
- **기각**: 합계 < **0.3pp** — §19 측정하한 미만은 이 프로토콜로 주장 불가

**사전 최우선 의심 (§1f 확인 후 교정된 순위)**:
1. **nasdaq_session_tape — 동일봉 진입.** 세션 테이프로 신호를 만들고 **같은 날 종가**에 진입한다.
   신호가 그날 종가 정보를 조금이라도 흡수하면 누출이고, 아니어도 종가 체결은 비현실적이다.
   **사전 예측 박제**: 진입을 **익일 max(open, 종가)** 로 옮기면 Δ_entry ≤ **−0.5pp**.
2. **kospi_intraday_t5 — 스캔일 종가 진입.** 위와 같은 구조. 단 청산은 `fill = max(tgt, open)`으로
   이미 보수적이므로, 비대칭(진입 낙관 / 청산 보수)의 순효과를 부호까지 측정한다.
3. **b 계열 — cost = 0.0 가정.** `alpha`가 시장중립 α라는 이유로 왕복비용을 0으로 두었다.
   α는 비용을 면제하지 않는다(실거래는 여전히 왕복비용을 낸다). **사전 예측**: 실측 비용 0.3~0.6pp를
   부과하면 b_all_top10 부족분의 20~40%가 설명된다. 단 **부호는 이미 음수**이므로 이것만으로는
   사망 판정이 뒤집히지 않는다 — 기여도 계산에만 반영한다.
- **재검증하지 않음**: 터치익절 체결 가정 — §40 PKG-B ③ / `research/harness_2026_07/touch_fill_verification.py`
  에서 통과(EV 임팩트 −0.04pp). 인용만 하고 재실행하지 않는다.

## 6. 중요도 하한 (연 기여 1%p)

```
ΔEV_min(pp) = max( 1.0 / (N_yr × f) , 0.3 )        f = 픽당 총자본 비중 = 0.02
N_yr        = min( 발행률 × 245 , (0.20 / f) × 245 / 보유일 )   ← §40 PKG-B ① 슬리브 용량 캡
```

**산정 예**(보유 5일, f=2% → 동시 10픽 → 2픽/일 → N_yr = 490):
`1.0 / (490 × 0.02) = 0.10pp` → **하한 = 0.30pp (§19 측정하한이 지배)**.

규칙:
- 수리로 회복되는 ΔEV < **0.3pp** → 실재해도 **레인화 금지**. 피처/게이트/베토로만.
- 수리 후 **절대 net EV < ΔEV_min** → 부활 불가(등급 B 실패).
- 레인 전체 연 기여 = `N_yr × f × EV_post`. 이 값이 **< 1%p**면 부활시켜도 "**조연**" 등급 —
  발행 복원 권고 금지, 관측 레인으로 유지.
- N_yr은 **발행 픽수가 아니라 용량 캡 후 픽수**다(§40 실측: 미정산 52픽 노출 104%p vs 예산 20%p
  — 발행 픽수를 그대로 쓰면 5배 과대계상된다).
