Author: Claude / 결정: 운영자. 모든 가설은 [가설 → 검증 방법 → 통과 기준 → 킬 기준] 형식.
전제: 20여 실험의 메타 결론(§9-E) — 엣지는 테이프·계약/발행 구조·레짐-프로필 상호작용에 있고,

## 0. 재귀 학습 루프 (인프라 — 배포 완료)

```
레인 원장(자동채점) → 재귀 게이트(daily: report_research_recursion_gate.py)
  ├─ CONFIRM  → 계속 + 표본 확대
  ├─ DEGRADE  → beads 재연구 티켓 자동 발행 + 사이징 축소 권고
  └─ EXCEED   → 승격/확대 검토 티켓 자동 발행
→ 재연구(가설 큐에서) → 계약/모델 갱신 → 다시 원장 (사람은 승격/축소 결정점만)
```
- 레인별 동결된 백테스트 기대치(연구 로그 §7-E/§11/§12 근거)와 forward CI를 자동 비교.
- 티켓 중복 방지(판정 변화 시에만 발행). 첫 판정: 전 레인 OBSERVING (표본 성숙 대기).
- 스윙 앙상블은 벌써 fwd −0.5 (n=20) — n≥30 도달 시 DEGRADE 티켓이 자동으로 뜰 전망.
